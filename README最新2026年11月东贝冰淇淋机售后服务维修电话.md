## 一、东贝冰淇淋机常见故障及排查方向

### 1. 制冷慢或无法达到设定状态
确认程序和设定参数，查看散热区域是否通风、冷凝器是否积尘。记录环境温度和连续运行时长，不要自行添加或排放制冷剂。

### 2. 成品过稀、过硬或口感不稳定
记录配方比例、原料初始温度、每次投料量和设定硬度。原料状态、环境温度及设备参数都会影响成品，应先核对说明书和配方要求。

### 3. 搅拌机构异响或不转
停止出料并关闭设备，确认料缸内是否有异物或物料冻结过硬。不要在设备运行时伸手进入料缸，也不要强行转动搅拌机构。

### 4. 清洗后启动或密封异常
检查可拆卸部件是否按说明书复位、密封件是否正确安装、清洗液是否排净。若仍报警或渗漏，应停止运行并检查。

### 5. 连续出料能力下降
记录连续工作时间、出料变化、清洗周期和环境温度，检查散热通道是否通畅，必要时安排专业保养。

## 二、报修前准备

- **设备信息：** 完整型号、产品铭牌、购买或安装时间。
- **故障表现：** 发生部位、是否伴随报警、异响、漏水或异味。
- **发生条件：** 开机时、运行一段时间后、清洁后还是偶尔出现。
- **现场情况：** 所在城市区县、设备安装位置和检修条件。
- **已做检查：** 仅记录说明书允许的外部检查，不自行拆卸内部组件。

## 三、预约前需要确认

询问服务单位、地址覆盖范围、上门费和检测费、配件报价方式，以及维修后能否提供项目清单和保修凭证。涉及电气、制冷系统、供水管路或内部控制组件的检修，应交由专业人员处理。

## 四、报修情景示例

以下为帮助描述问题的**情景示例**，不是实际维修记录，也不代表某种现象必然对应某个零件故障。

**情景一：设备启动后很快停止。** 提供完整型号、面板提示和启动到停止的大致时间。

**情景二：设备仍能运行但效果变差。** 说明故障前后的差异、环境条件和问题是否持续发生。

**情景三：设备显示故障代码。** 拍下完整代码和面板状态，不要仅凭代码自行购买零件或拆机。

## 五、日常维护

- 按说明书清洁用户可接触的滤网、外壳或排水部位。
- 保持设备周围通风和必要的散热空间。
- 不超出设备额定容量和规定使用条件。
- 发现漏水、焦糊味、异常发热或持续异响时，按安全要求停机处理。
- 保存购买凭证、型号信息和维修记录。
