联系前请准备产品完整型号、购买或安装时间、所在省市区县、故障发生时间和具体表现。先说明设备状态和已做过的基础检查，再确认服务范围、上门或检测费用、配件报价及维修后的保修约定。

## 一、星月神智能锁常见故障及排查方向

### 1. 指纹、密码或卡片无法识别
确认录入方式、手指状态和输入内容，观察低电量或锁定提示，不要连续试错。

### 2. 电池电量低或锁具无电
按说明书更换规定规格电池；应急供电仅使用指定接口和电源。

### 3. 验证成功但门打不开
记录把手、锁舌动作和门扇是否受门框挤压，不要强扭把手或拆锁体。

### 4. 关门后锁舌卡住
观察门扇是否下垂、门缝是否变化及锁舌扣板是否对齐。

### 5. 联网或临时密码异常
记录手机端提示、锁具型号和网络环境，不要向他人透露管理员密码或验证码。

## 二、报修前准备

- **设备信息：** 完整型号、产品铭牌、购买或安装时间。
- **故障表现：** 发生部位、是否伴随报警、异响、漏水或异味。
- **发生条件：** 开机时、运行一段时间后、清洁后还是偶尔出现。
- **现场情况：** 所在城市区县、设备安装位置和检修条件。
- **已做检查：** 仅记录说明书允许的外部检查，不自行拆卸内部组件。

## 三、预约前需要确认

询问服务单位、地址覆盖范围、上门费和检测费、配件报价方式，以及维修后能否提供项目清单和保修凭证。涉及电气、制冷系统或锁体内部组件的检修，应交由专业人员处理。

## 四、报修情景示例

以下为帮助描述问题的**情景示例**，不是实际维修记录，也不代表某种现象必然对应某个零件故障。

**情景一：设备启动后很快停止。** 提供完整型号、面板提示和启动到停止的大致时间。

**情景二：设备仍能运行但效果变差。** 说明故障前后的差异、环境条件和问题是否持续发生。

**情景三：设备显示故障代码。** 拍下完整代码和面板状态，不要仅凭代码自行购买零件或拆机。

## 五、日常维护

- 按说明书清洁用户可接触的滤网、外壳或排水部位。
- 保持设备周围通风和必要的散热空间。
- 不超出设备额定容量和规定使用条件。
- 发现漏水、焦糊味、异常发热或持续异响时，按安全要求停机处理。
- 保存购买凭证、型号信息和维修记录。
