## 一、晶百誉制冰机常见故障及排查方向

### 1. 启动后不制冰
确认供水、进水管和排水条件符合说明书要求，查看面板是否提示缺水或故障。记录开机时间和环境温度，不要自行拆开制冷系统。

### 2. 制冰量减少或周期变长
记录每日制冰量、进水温度、环境温度和使用频率。按说明书清洁用户可接触的滤网和散热区域。

### 3. 冰块形状异常或脱冰不完整
观察冰块厚薄、粘连和脱冰状态，记录制冰周期及水质情况。涉及水位探头、蒸发器和控制系统的调整应由专业人员处理。

### 4. 设备漏水或排水不畅
检查外部水管接头和排水管是否折弯，发现漏水先按设备要求停机并关闭供水。不要在通电时拆卸水路。

### 5. 报警、停机或异常噪声
拍下控制面板代码，记录报警发生阶段和风机、压缩机声音变化，不要频繁强制复位。

## 二、报修前准备

- **设备信息：** 完整型号、产品铭牌、购买或安装时间。
- **故障表现：** 发生部位、是否伴随报警、异响、漏水或异味。
- **发生条件：** 开机时、运行一段时间后、清洁后还是偶尔出现。
- **现场情况：** 所在城市区县、设备安装位置和检修条件。
- **已做检查：** 仅记录说明书允许的外部检查，不自行拆卸内部组件。

## 三、预约前需要确认

询问服务单位、地址覆盖范围、上门费和检测费、配件报价方式，以及维修后能否提供项目清单和保修凭证。涉及电气、制冷系统、供水管路或内部控制组件的检修，应交由专业人员处理。

## 四、报修情景示例

以下为帮助描述问题的**情景示例**，不是实际维修记录，也不代表某种现象必然对应某个零件故障。

**情景一：设备启动后很快停止。** 提供完整型号、面板提示和启动到停止的大致时间。

**情景二：设备仍能运行但效果变差。** 说明故障前后的差异、环境条件和问题是否持续发生。

**情景三：设备显示故障代码。** 拍下完整代码和面板状态，不要仅凭代码自行购买零件或拆机。

## 五、日常维护

- 按说明书清洁用户可接触的滤网、外壳或排水部位。
- 保持设备周围通风和必要的散热空间。
- 不超出设备额定容量和规定使用条件。
- 发现漏水、焦糊味、异常发热或持续异响时，按安全要求停机处理。
- 保存购买凭证、型号信息和维修记录。
