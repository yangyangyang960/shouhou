# 老板燃气灶售后维修电话｜故障报修与使用维护指南

联系前请准备燃气灶完整型号、所在城市、购买或安装时间、故障炉头位置，以及故障出现时的具体表现。报修时先说明现象，再确认服务范围、上门和检测费用、配件报价及维修后的保修约定。

## 一、老板燃气灶：嵌入式安装与单侧炉头问题

### 1. 嵌入式灶具点火或燃烧不稳定
报修时说明台面开孔、橱柜空间和灶具安装年限，并提供产品铭牌信息。不要自行抬起灶具或拆动燃气连接，安装空间和通风情况应由专业人员检查。

### 2. 只有一侧炉头火焰异常
记录左右两侧的差别、异常炉头是否刚清洁过，以及炉头盖是否正确复位。待冷却后按说明书检查可拆卸部件，不要自行拆卸喷嘴。

### 3. 面板清洁后旋钮周围出现积水
先停止使用并等待设备完全干燥，清洁时避免液体流入旋钮、点火和电气部位。若干燥后仍有异常，不要反复操作，应联系专业人员。
## 二、报修前建议准备的信息

- **产品型号：** 查看产品铭牌或购买资料，记录完整型号。
- **故障位置：** 左炉头、右炉头、全部炉头，以及台式或嵌入式等基本类型。
- **现象描述：** 无火花、点火后熄火、火焰异常、旋钮异常或其他情况。
- **发生条件：** 冷机启动、连续使用后、清洁后，还是偶尔出现。
- **安全情况：** 是否有燃气异味、异常声响或可见损坏；出现燃气异味时立即停止排查并先确保人员安全。

## 三、预约维修前需要沟通的事项

拨打售后维修电话后，说明品牌、型号、所在地区和故障表现。预约前确认是否覆盖所在地址、是否收取上门费或检测费、维修项目如何报价、配件是否单独计费，以及维修后能否提供费用清单和保修凭证。涉及燃气管路、燃气阀、燃烧器、点火和熄火保护装置的检修，应交由专业人员处理。

## 四、报修情景示例

以下是帮助用户描述故障的**情景示例**，不是实际上门维修记录，也不代表某种现象必然对应某个零件故障。

**情景一：一个炉头有点火声但没有点着。** 说明是否看见火花、另一个炉头能否正常使用、是否刚清洁过，以及是否伴随异味。

**情景二：火点着后松开旋钮就熄灭。** 说明需要按住多久、火焰是否稳定、问题是否只发生在一个炉头，便于安排针对性检查。

**情景三：两个炉头火焰都比平时小。** 说明变化时间、家中其他燃气器具是否也受影响，不要自行调整阀门或拆卸管路。

## 五、日常使用和安全维护

- 使用时保持厨房通风，灶具周围不要堆放纸张、抹布等易燃物。
- 清洁前关闭灶具并等待冷却，避免水分进入点火和电气部位。
- 炉头部件拆洗后按说明书正确装回，不要强行安装。
- 不自行拆卸燃气阀、点火器、熄火保护装置或改动燃气管路。
- 若闻到燃气味，不要点火或操作电器开关，尽快离开现场到室外安全区域，再联系当地燃气应急服务。
